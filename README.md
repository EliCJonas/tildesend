<p align="center">
  <i>A program for sharing files between users on Tildes, shared PUBNIX computers.</i>
</p>

---

Usage:

```bash
snd (transfer ID) (file to transfer)
```

Transfer ID is something you set for your transfer. After running this command, before pushing Return, have the other user do:

```bash
rcv (transfer ID)
```

Then you can push Return to destroy the transfer.
